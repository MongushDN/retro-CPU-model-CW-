Цель курсовой: построить эмулятор ретро-процессора. 
Задачи: Выбрать модель. Разобрать её характеристики. Написать программу на С++, которая моделирует процессор. Добавить понятную для 
пользователя графику.
Актуальность: эмулятор ретро процессора будет наглядной моделью для тех, кто хочет разобраться с работой процессоров на начальных этапах.
Было несколько вариантов ретро-процессоров, из которых я выбрала основывать нашу работу на Intel 8080. 
Характеристики Intel 8080:
    Год создания - 1974.
    Разрядность - 8 бит.
    Адресация - прямая, косвенная, стековая. Линейная, а не страничная.
    Регистры - А+6РОН+стек. (6 регистров общего назначения, которые могут объединяться в пары) (планируем меньше А+4РОН)
    Флаги - Z, C, S, P, AC.
    Память - 64 ГБ. (Но мы планируем 256 ячеек)
Особенность Intel 8080 в том, что он стал прототипом для будущих процессоров, а компания, выпустившая его, до сих пор занимает мместо в рынке 
процессоров. Это делает данный обозрение Intel 8080 более релевантным для обозрения в сравнении с другими старыми моделям. 


Теория: 
Далее примитивные операции, часть из которых уже была в Intel 8080, а часть появилась в процессорах позже.
Процессорные программы:
    Работа с данными и памятью:
        Установить значение регистра в значение константы. Да.
        Копирование значения из памяти в регистр и обратно. Да.
        Чтение и запись данных с прочих устройств. Да. 
    Арифметические и логические:
        + - * /  значения из 2х регистров, запись результата в 3й регистр. (+- частично, */ - нет.) !!!
        Выставление флагов с статусных регистрах. Да.
        Инкремент декремент. ++ -- Да.
        Побитовые операции. а^а^а^а  AND OR XOR Да.
        Сравнение значений в 2х регистрах. (<, >, =) Да.
        Операции с числами с плавающей точкой. НЕТ.!!!
    Операции управления потоком:
        Ветвление вглубь кода. Да.
        "Ветвление" в другое место кода в случае выполнения определённого условия. Да.
        Неявное ветвление в другое место в коде. Да.
        Вызов другого блока кода, с сохранением адреса текущего для возможности возврата. ДА.
    Инструкции сопроцессора: Нет!!! 
        Чтение/запись данных между процессором и сопроцессором. Нет.!!!
        Выполнение операций сопроцессора. Нет.!!!

Аккумуляторная архитектура — это ключевая особенность 8080. Все арифметические операции происходят только с аккумулятором A 
    ADD B   ; A = A + B
    SUB C   ; A = A - C
Результат всегда попадает в A, а не в произвольный третий регистр. Это упрощает эмуляцию, потому что не нужно решать, куда сохранять результат.
Флаги в 8080:
    Z (Zero) — результат равен нулю
    S (Sign) — результат отрицательный
    CY (Carry) — был перенос/заём
    P (Parity) — чётность результата
    AC (Auxiliary Carry) — перенос из младшего полубайта (для десятичной коррекции) 
Побитовые операции — полный набор: AND, OR, XOR .
Ветвление — мощное и гибкое. Есть 8 условий для JMP и CALL:
    Z (ноль), NZ (не ноль)
    C (перенос), NC (нет переноса)
    P (положительный), M (отрицательный)
    PE (чётность), PO (нечётность) 
Стек — 16-битный SP, работает "последним пришёл — первым ушёл". PUSH и POP работают только с 16-битными регистровыми парами (BC, DE, HL, PSW)
